# EcoBridge HPC - Local Challenges & Global Infrastructure

Studi kasus interaktif berdasarkan materi kuliah praktisi Informatika Universitas Bengkulu. Proyek ini mendemonstrasikan antarmuka simulasi berbasis High Performance Computing (HPC) dan AI untuk menyelesaikan tantangan lokal (mitigasi bencana, pertanian cerdas, dan analisis data).

## 🚀 Live Demo
Akses website secara online melalui tautan berikut:
[https://ayusaraswati25.github.io/ecobridge-hpc/materi2.html](https://ayusaraswati25.github.io/ecobridge-hpc/materi2.html)

## 🛠️ Fitur Utama
- Modul Simulasi (Flood Forecast, City Evacuation, Digifarm Land Mapping, Minority Speech).
- Pengaturan Parameter Node HPC dan Presisi Floating Point.
- Live Terminal System Log interaktif.
